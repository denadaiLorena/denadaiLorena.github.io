# Denadai Lorena – Portfolio Site

A clean, responsive Jekyll theme for a personal website and project showcase. The site automatically respects the user's **dark‑mode** preference and works on mobile and desktop.

## Features
- Responsive layout with a lightweight CSS base
- Dark‑mode support (via CSS media query)
- Dedicated **Projects** page that displays project cards automatically
- Simple configuration through `_config.yml`

## Quick start
```bash
# Clone your fork
git clone https://github.com/<your‑username>/denadaiLorena.github.io.git
cd denadaiLorena.github.io

# Install dependencies (Ruby & Bundler required)
bundle install

# Serve locally
bundle exec jekyll serve
```
Open `http://localhost:4000` in your browser to see the site.

## Documentation
Further details on customizing the theme, adding new pages, and deploying to GitHub Pages are in the [_config.yml](./_config.yml) file and the `README.md` of the original **Gradfolio** theme.
